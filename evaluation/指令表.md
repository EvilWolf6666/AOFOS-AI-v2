:: ══════════════════════════════════════════════════════════════
:: 1. 產評分表（第一輪從這裡開始）
::    輸出：記錄表.盲評版.<評審>.md ×N ＋ 記錄表.對照表.json
:: ══════════════════════════════════════════════════════════════
python evaluation\blind_eval.py make evaluation\記錄表.md ^
  --seed 42 ^
  --raters GPT,Claude,Gemini ^
  --questions evaluation\題本_v2.md ^
  --rubric evaluation\判準_v2.md

::   記錄表.md    位置參數，填完輸出與自己那欄分數的那份
::   --seed       固定逐題洗牌順序。不給,會自動產一個寫進對照表
::                但事後想重跑同一順序就做不到了。建議每輪都給
::   --raters     用逗號來分隔。每位一份獨立檔案
::   --questions  題本。只會注入 <!-- 給評審 --> 內的題目情境
::                標準答案不會跟著出去
::   --rubric     判準。注入每題的判分界線
::   （選）--outdir evaluation\20260910輪   想按輪次分資料夾時加
::
::   (對照表 .json 自己留著，交分數前不要打開給任何評分者看)


:: ══════════════════════════════════════════════════════════════
:: 2. 先看自己那欄（評審分數回來前，順便驗記錄表格式）
:: ══════════════════════════════════════════════════════════════
python evaluation\blind_eval.py merge --key evaluation\記錄表.對照表.json ^
  --record evaluation\記錄表.md

::   --record  直接讀記錄表裡的 **評分**：n/2，不必手抄成代號


:: ══════════════════════════════════════════════════════════════
:: 3. 開盲合併（各評審填完收回後）
:: ══════════════════════════════════════════════════════════════
python evaluation\blind_eval.py merge --key evaluation\記錄表.對照表.json ^
  --record evaluation\記錄表.md ^
  --scores evaluation\記錄表.盲評版.GPT.md evaluation\記錄表.盲評版.Claude.md evaluation\記錄表.盲評版.Gemini.md

::   --scores  空白分隔，可給任意多個（--raters 才是逗號，兩個容易記混）
::   輸出：逐評分者分數表 → 各組平均與兩兩差距 → 門檻判讀 → 語言瑕疵標記


:: ── 共通 ──────────────────────────────────────────────────────
::   ^ 後面不能有空格，有的話那行就斷了，而且不會告訴你原因
::   離開碼：0 正常／1 格式或尺度有問題／2 找不到檔案
::   分數 0～2，可用 0.5。填 1.37 會整批擋下並指出行號，不自動四捨五入
::   題數或尺度變了 → 程式宣告「門檻已失效」，不自行外推新門檻
